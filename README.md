# 竞品舆情自动分析 Agent

一个基于 Python、LLM API 和 Agent 工作流的竞品监测与舆情分析项目。

项目能够自动获取竞品公开信息，调用 DeepSeek 模型进行分析，并生成结构化的竞品舆情日报，最终保存为本地文件或推送至飞书群。

## 项目背景

运营或市场人员需要持续关注多个竞品的官网、公开信息和社交媒体动态。

如果完全依靠人工进行信息收集和整理，会占用较多时间，也容易遗漏重要信息。

因此，本项目尝试将：

**信息采集 → 信息分析 → 报告生成 → 消息推送**

这一流程进行自动化。

---

## 核心功能

### 1. 竞品信息采集

并发请求配置的竞品 URL，获取网页公开内容并提取有效文本。

当前支持：

- 竞品 URL 配置
- 网页内容获取
- 文本提取
- 请求异常处理

后续可以扩展 RSS、API 等数据来源。

### 2. LLM 信息分析

将采集到的竞品信息提交给 DeepSeek 模型进行分析。

主要完成：

- 关键更新提取
- 产品动态识别
- 人事 / 活动等信息识别
- 情感倾向判断
- 生成简短竞品动态摘要

通过约束模型输出 JSON，使后续程序能够对分析结果进行结构化处理。

### 3. 报告生成

将多个竞品的分析结果统一整理为 Markdown 格式的日报。

报告包含：

- 竞品名称
- 情感倾向
- 关键更新
- 简短动态摘要

### 4. 飞书推送

支持将生成的 Markdown 报告通过飞书机器人 Webhook 推送到群聊。

如果未配置飞书 Webhook，则保存为本地文件。
