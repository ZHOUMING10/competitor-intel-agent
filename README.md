# 竞品舆情自动分析 Agent

一个基于大模型的智能竞品监测系统，自动抓取、分析、推送竞品动态。

## 解决的痛点

运营/市场人员每天需手动刷多家竞品官网、社媒，耗费大量时间，且容易遗漏关键信号。本 Agent 将整个过程自动化，并能以结构化报告形式推送到飞书群。

## 核心逻辑流

1. **数据抓取 Agent**：并发请求竞品 URL，提取有效文本（可扩展为 RSS、API 接入）
2. **多维分析 Agent**：调用 DeepSeek 模型，强制输出 JSON，完成：
   - 关键更新提取（产品/人事/促销）
   - 情感倾向判定
   - 80 字简报生成
3. **报告与推送 Agent**：组装 Markdown 日报，推送飞书群或保存为文件

整个过程体现了"感知-分析-行动"的智能体闭环。

## 多 Agent 协作与长链推理

- 抓取失败时，分析阶段会接收错误信息并标记状态，不会中断流程
- 分析 Agent 实际包含"信息提取子任务"和"情感判断子任务"，通过单次推理内链式完成

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY

# 3. 运行
python agent.py
```

## 配置说明

| 环境变量 | 必填 | 说明 |
|---------|------|------|
| DEEPSEEK_API_KEY | ✅ | DeepSeek API Key |
| FEISHU_WEBHOOK | ❌ | 飞书机器人 webhook，不填则保存本地 |

## 运行示例

```
--- 处理 竞品B ---
[采集] 竞品B 数据获取成功，长度: 2000 字符
[分析] 竞品B 分析完成

# 竞品舆情日报 (2026-04-29 18:50)

## 竞品A
**情感倾向**: 积极
**关键更新**: 新品发布、促销活动
> 竞品A 今日发布新一代产品...

> 竞品B 本周无重大更新...

```
